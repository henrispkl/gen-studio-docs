Run the stale steps

Rebuild the steps that were made from a take you no longer use.

A step is stale when a take it was made from is no longer in use. Say you use concept Take 3 instead of Take 1: the Prepped cut-out, Mesh and Game mesh were made from Take 1, so they're stale until they run again.

Stale isn't an error. The old results are still there.

See what's stale​

  • On the rail, stale steps have the stale colour.
  • The step's title bar says stale: and what changed.
  • Home's Waiting for you has a card for it, and Assets has a Stale filter.
  • gen status still lists them.

Rebuild them​

  1. Open the asset.
  2. Press Re-run stale in the toolbar. It only shows when something is stale.

Each stale step runs again from the takes now in use, in order. Each makes a new take, and that take is used.

Takes built on a take​

A take made with Build on Take N (a stack of Retouch or Edit passes, say) gets its picture from that other take, not from the step before. Running it again would keep the old pixels, so Re-run stale and Run to here leave it, and the steps after it, marked: the title bar says rebuild by hand.

To rebuild one, start from New take on that step, with Starts from set to Original, and make the passes again. Or use the old take of the step before again, and the mark goes.

Other ways​

  • Run to end runs every step that's missing or stale, to the end or the next review.
  • Right-click a step → Run to here rebuilds up to that one only.
  • Auto-continue makes a finished step start the next one by itself, up to the next review. It's set per project.

From the command line​

gen rerun-stale still        # every stale step, a character's clips too
gen run-to still retopo      # only up to the Game mesh

Tips​

  • Export to Godot refuses a stale asset, so Godot never gets a half-updated model.
  • Liked the old result better? Use the old take again, and the steps after it aren't stale any more.
