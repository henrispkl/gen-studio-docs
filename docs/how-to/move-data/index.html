Move your data

Move Gen Studio's data folder to a bigger disk, see what uses the space, and reuse model files you already have.

The data folder holds the model weights, the worker environments, the managed ComfyUI and llama.cpp, caches and gen.db. It's ~/.local/share/gen-studio/ by default and can grow past 100 GB. Your projects live elsewhere and aren't moved.

To keep only the models on another drive, use libraries instead. It's the simpler choice for most people.

Before you start​

  • An empty folder on the new disk, with room for everything (check with What uses the space below).
  • Nothing running: let the queue finish or pause it.

Move the data folder​

  1. Open Settings (Ctrl+,) and pick Storage.
  2. Under Data folder, press Move… and pick the empty folder.
  3. Wait for it to finish. It copies everything, checks every file arrived at its size, then leaves a link at the old path, so every setting keeps working.
  4. When it says Moved, it shows where the old copy is (renamed <old>.moved-<time>). Delete that copy yourself once everything works.

Settings → Storage.

From the command line:

gen data move /mnt/bigdisk/gen-studio

To move it back, run gen data move with the original path: the link is replaced by the real folder.

See what uses the space​

What uses the space on the Storage page (or gen data usage) lists, biggest first: each extension's weights, each project, caches, runtimes, worker environments, and weight files no installed extension names (orphans).

  • Remove beside weights deletes those model files. Steps that need them won't run until you install them again.
  • Remove beside a cache is safe: it is rebuilt as you use the app.

Reuse model files you already have​

If you downloaded some weights before (for ComfyUI, say), Gen Studio can use them instead of downloading again.

  1. Press Import model files… on the Storage page and pick the folder that holds them.
  2. Every file whose size and sha256 match a pinned weight is linked (or copied) into place.
gen data import ~/ComfyUI/models

Clear old takes​

Under Clean up → Old takes (the last group on the Storage page), Gen Studio counts the takes in this project that are not in use, not favourites, and over 14 days old. Move to .trash moves them to the project's .trash/. Nothing is deleted until you empty .trash/ yourself.

Tips​

  • To start with the data folder somewhere else, set data_dir in ~/.config/gen-studio/config.toml before the first install.
  • The uv cache (~/.cache/uv) is separate and can be large too; it isn't moved.
  • After a move, gen doctor checks the disk, GPU and runtimes.
