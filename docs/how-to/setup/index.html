Install and set up Gen Studio

You get Gen Studio installed, with the models for what you want to make downloading in the background while you use the app.

The first time you open Gen Studio, a Set up Gen Studio window opens over the app. You make a few choices, and each kind of asset works as soon as its models arrive.

Before you start​

  • Linux and an NVIDIA GPU. Gen Studio is built and tested on an RTX 4090 with 24 GB. Many steps want 16 to 24 GB of graphics memory. Smaller cards can run the Fast profile and fall back when a step doesn't fit. With no NVIDIA GPU, you can point it at a ComfyUI on another machine.
  • Disk space. 80 GB for the Minimal tier, 266 GB for Recommended, 358 GB for Full. The setup window shows the exact plan per drive before anything downloads.
  • Godot 4, for your game.
  • Blender on your PATH. The game mesh step, Paint and importing models use it. gen doctor says whether it's found.
  • uv, to install. While Kasumi, the app's UI framework, is a private repository, installing also needs SSH access to it on GitHub.

Install​

packaging/install.sh    # from a checkout: installs gen, gen-app and gen-mcp
gen-app                 # opens the app and the setup window

There's also an AUR package, packaging/aur/PKGBUILD.

  • In the app
  • Command line

The steps are on the left, and you can go back to any of them. The plan, under them, shows where models go, the tier, the packs, what downloads and how much room is left. It changes as you choose.

  1. Welcome: Express takes the suggestion for this machine and goes straight to the plan. Custom shows every step. Not now closes the window. Home then shows a row to finish setup, with Open setup.
  2. System check: the GPU and its memory, the driver and CUDA, RAM, each drive's free space, uv and Hugging Face. It never stops you. It says which profile new assets start at: Balanced from 20 GB of graphics memory, else Fast.
  3. Where models go: one row per drive, with what the plan needs against its free space. Your data folder stays where it is. Pick another drive and the models go to a library there. Choose folder… picks any folder.
  4. What to install: the tier, Minimal (props and characters at Fast), Recommended (every kind at Fast and Ultra fast) or Full (every profile). Then the packs: 3D, Audio, Effects, Text and LLM, Anime (off by default) and Gated models. An unticked pack isn't switched off: its models download the first time you use them, after the app asks.
  5. Import models: model folders you already have (ComfyUI's models/, the Hugging Face cache, Stability Matrix, LM Studio). Ticked files are checked by sha256 and linked, so they aren't downloaded again. Skip if you have none. On the same page you can paste a Civitai API key. Leave it empty to skip (Settings → Downloads has it too).
  6. Install: queues the work: imports, ComfyUI, the model environments, llama.cpp, then each pack's models. Each is a row with its progress, and they carry on after a restart. Continue in background closes the window.
  7. Ready: each pack is ready, downloading, queued, on first use or off. Make a first prop opens New asset.
gen setup                     # the same questions, the suggestion as the default
gen setup --express --yes     # take the suggestion and install
gen setup --tier minimal --packs 3d,audio --library /mnt/games --dry-run   # the plan and sizes only
gen setup --status            # per pack: ready, downloading, on first use
gen setup --resume            # queue again what failed
gen config civitai-key --set  # the Civitai API key
gen doctor                    # check the GPU, driver, disk and runtimes

gen setup follows the downloads until they finish. Ctrl-C stops following. The jobs stay queued, and the app or gen queue run carries on.

Run it again​

Settings → Setup → Open setup reopens the window. Install then queues only what's new: a pack you ticked, a bigger tier, models on another drive. To remove models, use Settings → Models.
