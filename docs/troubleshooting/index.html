Troubleshooting

Find what you see, read why, then try the fixes in order. A failed step's panel says what went wrong and has Copy log. gen doctor checks the GPU, the driver, disk space and the runtimes.

The app shows no project​

Why: the top bar says "No project open" and Assets is greyed out until a project folder is open.

  1. On Home, press New project…, pick a folder and a Target look.
  2. Or press Open folder… and pick a folder that has a gen-project.toml in it.

A step failed with "Ran out of GPU memory"​

Why: the model didn't fit beside what else uses the GPU: a game, a browser playing video, another AI tool. The message names the numbers: "needs about 21 GB of VRAM but only 9.5 GB is free".

  1. Look at Home's On the GPU to see what holds the memory, and close it. Gen Studio never stops a program it didn't start.
  2. Press Retake.
  3. If it still fails, pick a lighter Profile and retake.

A step that runs out of memory part-way goes again one profile lighter by itself. Its queue row then says "Fell back: ran at Fast", and the take records it.

A step says a model is "not installed"​

Why: that step's model hasn't been downloaded. The Recommended install leaves out models that only Balanced, Quality or a second Model choice use.

  1. In the app, press Download and run in the box that asks. It queues the download, then the step.
  2. Or press Run at Fast to run now with a model you have.
  3. In a terminal, run the command the message ends with: gen install weights --group <group>.
  4. To fetch every on-demand model at once: gen install weights --tier full (357.6 GB in all).

The CLI, batches and agents don't ask. They refuse with the install command. The groups are in the models reference.

"Something isn't installed"​

Why: a tool or runtime the step needs is missing. The message says which.

  1. "not installed (gen install workers)": run gen install workers from the Gen Studio folder.
  2. "llama.cpp isn't installed": run gen install llama.cpp.
  3. "ComfyUI: not installed" in gen doctor: run gen install comfyui.
  4. "the writing helper isn't installed": install the Text tools models in Settings → Models.
  5. "Blender is not on PATH" or "ffmpeg isn't installed": install it with your system's package manager.
  6. Or press Settings → Setup → Open setup and let Install queue what's missing.

A kind or a step doesn't show, or "no installed extension provides the … stage"​

Why: the pack that has it is off. The anime pack (gen.anime) and the pixel art and chiptune pack (gen.pixel) ship off.

  1. Open Settings → Extensions and switch the pack on. Or run gen ext enable gen.anime.
  2. Restart the app. A change applies on the next start.
  3. Install its models in Settings → Models, or let them download the first time a step asks.

A Kit says "Kits need the … extension on" for the same reason. See extensions on and off.

Export refuses: "has stale steps"​

Why: a step was built from a take you no longer use, and export won't send Godot a half-updated asset.

  1. Open the asset and press Re-run stale.
  2. Or use the old take again, and nothing is stale.
  3. Export again.

A take marked rebuild by hand was built on another take. See run the stale steps.

"Godot 4.7 not found on PATH", or "is not a Godot project"​

Why: steps that check their result in Godot, and export, need Godot 4.7 and a real project folder.

  1. Install Godot 4.7 so that godot runs in a terminal. "need Godot 4.7.x, found …" means another version is first on your PATH.
  2. For export, pick the folder that holds project.godot.

A step says a drive "isn't connected"​

Why: the model is in a library on a drive that isn't mounted.

  1. Connect the drive. The app checks every 10 seconds.
  2. Open Queue, hover the failed row and press Retry.
  3. If the drive mounts somewhere else now, see libraries and drives, or run gen doctor --relink.

"The model took too long to start" or "The model's process crashed"​

Why: the model's worker didn't come up in time, or it exited.

  1. Press Retake once the GPU is free. A crashed worker is restarted once by itself.
  2. If it happens again, press Copy log and read the last lines.
  3. Run gen doctor.

"Gen Studio hit a bug" or "The extension answered unexpectedly" is not something you did. Please report it with the log.

"… is running or queued; cancel it first"​

Why: you tried to delete a step while it, or a step after it, has a job.

  1. Open Queue and cancel the job, or right-click the step → Cancel its runs.
  2. Try again.

A download asks for a login​

Why: some Civitai files need an account, and some models on Hugging Face are gated behind a licence you accept on their page.

  1. Civitai: paste your API key in Settings → Downloads.
  2. A gated model: accept its licence on its Hugging Face page, then install it by name, for example gen install weights --group sonicmaster.

The model looks wrong in Godot​

  • Too dark or flat: the export uses the baked texture. At PS1 and PS2 it's palette-reduced on purpose.
  • Too many or too few polygons: the budget comes from the target look. Set the Game mesh step's Triangle budget.
  • Parts are missing (a cart's wheel spokes, a lantern's ring handle): thin parts go first. Retake Mesh at Balanced or Quality, or make the concept simpler.

A character's left and right are swapped​

Why: the 3D model needs four fixed views, and the Turnaround got one wrong. It warns when it can't tell.

  1. Retake Turnaround.
  2. Run on from it.

A wearable pokes through the body​

Why: the piece sits too close, or the piece under it wasn't there when it was fitted.

  1. Raise Clearance (metres) and retake.
  2. For a piece worn over another, make the lower Layer first.
  3. wear.json in the take lists the poke per test pose.

Cloth doesn't move, or the take fails with "chains stretch"​

Why: the piece's words didn't name something that hangs, or the swing settings don't suit it.

  1. Doesn't move: set Cloth to cape, skirt, hair or tail.
  2. Too floppy, too stiff, or "the cape chains stretch 8% in Godot": change Cloth material. A take fails above 5 % stretch.

See cloth presets.

Something else​

  1. Run gen doctor.
  2. Press Copy log on the failed step and read the last lines.
  3. If the app's lists look wrong after you moved folders by hand, run gen doctor --reindex. It rebuilds the index from the asset folders.
