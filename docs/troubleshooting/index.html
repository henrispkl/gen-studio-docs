Troubleshooting

Each problem: what you see, why, and what to do.

A step failed: "Ran out of GPU memory"​

Why: the model didn't fit beside what else uses the GPU: a game, a browser with hardware video, another model.

Do: close what else uses the GPU, or retake at a lighter profile. Home's On the GPU shows what's holding the memory. A step that can falls back to the next lighter profile by itself and says so on the take ("Fell back: ran at Fast").

"Needs a download" or "not installed"​

Why: that step's model hasn't been downloaded. The default install leaves out models only Balanced or Quality use. A download icon beside a profile or an Add step card says so before you pick it.

Do: in the app, press Download and run (it queues the download, then the step) or Run at Fast. In a terminal, run the command the message gives: gen install weights --group <group>. The models reference lists the groups. gen install weights --tier full fetches every on-demand model at once.

The model looks wrong in Godot​

  • Too dark or flat: the export uses the baked texture. At PS1 and PS2 it's palette-reduced on purpose.
  • Faces inside out: retake the Game mesh step. It's a bug; please report the asset.
  • Too many polygons: the budget comes from the target look. Set the Game mesh step's Triangle budget, or the project's [budgets].

Parts are missing from a model​

Thin parts (a chair's legs, a still's stand) are what goes first. Retake Mesh at Balanced or Quality. Or fix the concept: a clean, simple shape builds better.

A character's left and right are swapped​

The Turnaround step warns when it can't tell. Retake it. The 3D model needs fixed 90° views.

A clip slides, or the feet float​

Clips stay in place by default; check the job file doesn't set in_place: false. For motion capture, film side-on with the whole body in frame.

A wearable pokes through the body​

Raise Clearance and run on from Fit. For a piece over another, check the lower piece was made first. wear.json in the take lists the poke per test pose.

Cloth doesn't move, or explodes​

  • Doesn't move: the piece's words didn't name a hanging kind. Set Cloth to cape, skirt or hair.
  • Too floppy or stiff: change Cloth material (see cloth presets).
  • cloth_check in wear.json shows the swing and stretch measured in Godot.

The anime kinds don't show​

Turn the pack on in Settings → Extensions → gen.anime, restart the app, then gen install weights --group anime.

A drive is missing​

The step says which drive to connect. Plug it back in; the app checks every 10 seconds. If it mounts somewhere else now, see libraries and drives.

Export refuses​

  • Stale steps: run them first.
  • "is not a Godot project": pick the folder that holds project.godot.

Something else​

gen doctor checks Python, the GPU and driver, disk space and the runtimes. A failed job's panel has its log (Copy log).
