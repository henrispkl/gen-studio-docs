The gen command

Everything the app does, and more, from a terminal. Run it from a project folder, or pass --project. Each command's help is below, as gen <command> --help prints it.

usage: gen [-h] [--version]
           {setup,doctor,run,make,mcp,serve,dock,batch,import,find,status,outfit,promote,retake,reroll,run-to,add-step,branch,rerun-stale,discard,delete-step,export,install,ext,library,data,queue,new,update,restore}
           ...

Gen Studio

positional arguments:
  {setup,doctor,run,make,mcp,serve,dock,batch,import,find,status,outfit,promote,retake,reroll,run-to,add-step,branch,rerun-stale,discard,delete-step,export,install,ext,library,data,queue,new,update,restore}
    setup               set up Gen Studio: folder, tier, packs, imports, then
                        install
    doctor              check Python, uv, GPU, driver, disk and ComfyUI
    run                 run a job file through the slice, or check a meta.json
    make                quick job without a file, e.g. gen make prop "an oak
                        barrel"
    mcp                 Claude Code: add the MCP server and the gen-studio
                        skill
    serve               the queue on your phone (LAN page with a token)
    dock                the Gen Studio dock in a Godot project (talks to gen
                        serve)
    batch               queue many jobs from one file (jobs and a matrix)
    import              bring in a model you have (fbx, obj, glb, vrm, blend)
    find                search free models, textures, sounds, music, shaders
                        and voices
    status              an asset's step versions, canonical ones and stale
                        steps
    outfit              save a base body's named set of wardrobe pieces
    promote             make a candidate version of a step canonical
    retake              one more take of a step (kept until you promote it)
    reroll              a new seed for a take, replacing it (the old one's
                        pictures kept in rerolls/)
    run-to              build or refresh an asset's steps up to this one
    add-step            add a step after the last one of a path
    branch              start a new path from any step (b<n>/<stage>)
    rerun-stale         refresh every stale step of an asset, clips too
    discard             move a take that isn't in use to the project's .trash
    delete-step         move a step, the steps after it and paths from them to
                        .trash
    export              copy an asset's finished result into a Godot project
    install             install a managed runtime or model weights
    ext                 list or validate extensions
    library             library folders: where models and envs live
    data                the data folder: move it, see what uses the space,
                        import
    queue               work through queued jobs
    new                 scaffold a new extension
    update              write gen.lock from the installed extensions and
                        runtimes
    restore             install and verify exactly what gen.lock pins

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

gen add-step​

usage: gen add-step [-h] [--project PROJECT] asset after stage

positional arguments:
  asset
  after              the step it follows: the end of the main path or of a
                     b<n> path
  stage              what it runs, e.g. image_to_mesh (gen ext list shows
                     stages)

options:
  -h, --help         show this help message and exit
  --project PROJECT

usage: gen data [-h] {move,usage,import} ...

gen doctor​

usage: gen doctor [-h] [--reindex [PROJECT]] [--relink] [--verify]

options:
  -h, --help           show this help message and exit
  --reindex [PROJECT]  rebuild gen.db from a project's asset folders (default:
                       current project)
  --relink             rebuild the view's links from the online libraries
  --verify             --relink: match by sha256, not size

gen export​

usage: gen export [-h] [--step STEP] [--project PROJECT] asset godot

positional arguments:
  asset
  godot              the Godot project folder (has project.godot)

options:
  -h, --help         show this help message and exit
  --step STEP        export this step's take, e.g. the end of a path:
                     b1/retouch
  --project PROJECT

gen ext​

usage: gen ext [-h] {list,enable,disable,move,validate} ...

positional arguments:
  {list,enable,disable,move,validate}
    list                installed extensions (on or off) and their stages
    enable              turn an extension on
    disable             turn an extension off
    move                move an extension to another library (resumable)
    validate            check manifests, pins, envs and quality.toml

options:
  -h, --help            show this help message and exit

gen import​

usage: gen import [-h] [--asset ASSET]
                  [--as {character,prop,texture,sfx,music,shader,voice}]
                  [--licence LICENCE]
                  model

positional arguments:
  model                 a file, or a free asset's name from `gen find`

options:
  -h, --help            show this help message and exit
  --asset ASSET         asset name (default: from the file name)
  --as {character,prop,texture,sfx,music,shader,voice}
  --licence LICENCE     where it comes from, its licence

gen install​

usage: gen install [-h] [--group GROUP] [--library LIBRARY]
                   [--tier {minimal,recommended,full}] [--dry-run]
                   {comfyui,llama.cpp,weights,workers}

positional arguments:
  {comfyui,llama.cpp,weights,workers}

options:
  -h, --help            show this help message and exit
  --group GROUP         weights group (repeatable)
  --library LIBRARY     the library new files go to (weights, workers)
  --tier {minimal,recommended,full}
                        weights: Minimal, Recommended (default) or Full
  --dry-run             weights: list the groups and sizes, download nothing

gen library​

usage: gen library [-h] {add,list,remove,default} ...

positional arguments:
  {add,list,remove,default}
    add                 create or re-adopt <folder>/gen-studio-library
    list                id, label, status, free space, extensions, path
    remove              forget a library (refuses while used; never deletes)
    default             where extensions with no placement go

options:
  -h, --help            show this help message and exit

gen setup​

usage: gen setup [-h] [--express] [--yes] [--tier {minimal,recommended,full}]
                 [--packs PACKS] [--data DATA] [--library LIBRARY]
                 [--import IMPORTS] [--dry-run] [--resume] [--status]

options:
  -h, --help            show this help message and exit
  --express             take the suggestion for this machine
  --yes                 don't ask before installing
  --tier {minimal,recommended,full}
  --packs PACKS         comma-separated: 3d, audio, effects, text, anime,
                        gated
  --data DATA           the data folder
  --library LIBRARY     put models and envs in a library here
  --import IMPORTS      a folder of model files you have (repeatable)
  --dry-run             print the plan and sizes only
  --resume              queue again what failed
  --status              per pack: ready, downloading…
