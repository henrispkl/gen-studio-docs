Godot scripts

What Export copies into res://assets/gen/, and their functions.

wardrobe.gd​

Gen Studio wardrobe (spec 016): dress a base body at runtime. Each piece's .glb has a .wardrobe.json beside it (its slot, layer, the body vertices it covers and its cloth chains); outfits.json beside the body names sets of pieces.

Wardrobe.equip($Body, "res://assets/gen/coat/coat.glb")
Wardrobe.unequip($Body, "torso_outer")
Wardrobe.wear_outfit($Body, "res://assets/gen/hero/outfits.json", "travel")

One piece per slot is worn; putting one on takes off what was in its slot. The body under what's worn is hidden (its triangles left out), so it can't poke through.

  • static func worn(character: Node) -> Dictionary: What a character wears: slot -> {"path", "info"} (kept on the character as meta).
  • static func equip(character: Node, piece_path: String) -> void
  • static func unequip(character: Node, slot: String) -> void
  • static func wear_outfit(character: Node, outfits_path: String, outfit: String) -> void

wearables.gd​

Gen Studio wearables (spec 011): put a piece on a character at runtime. The piece's .glb shares the character's skeleton (same bone names and rest pose), so its meshes move onto the character's Skeleton3D and follow every animation.

Wearables.wear($Knight, preload("res://assets/gen/leather_boots/leather_boots.glb"))
Wearables.remove($Knight, "leather_boots")

A piece with cloth chains (spec 014: a cape, a skirt) brings its extra bones, and the .cloth.json beside it sets up a SpringBoneSimulator3D on the skeleton: one setting per chain, its material's stiffness, drag and gravity, capsule colliders on the body. A character's own chains (its long hair) come from its .cloth.json the same way:

Wearables.cloth($Girl, "res://assets/gen/girl/girl.cloth.json")

(the exported _cloth.tscn already does this).

  • static func wear(character: Node, piece: PackedScene) -> Array[MeshInstance3D]: Instance piece and move its meshes onto character's skeleton; returns them.
  • static func cloth(character: Node, path: String) -> void: Set up the simulator for a character's own chains (its hair) from its .cloth.json.
  • static func remove(character: Node, piece_name: String) -> void: Take off a piece put on with wear() (by its scene's name).

portrait.gd​

A Gen Studio sprite or portrait set: put this on an AnimatedSprite2D whose sprite_frames is the set's sprite_frames.tres. Each expression is an animation; "_talk" flaps the mouth and "_blink" closes the eyes, which happens by itself every few seconds.

  • func show_expression(name: String) -> void
  • func talk(on: bool) -> void

toon_apply.gd​

Gen Studio toon look: on load, every MeshInstance3D under this node gets toon.gdshader with its own albedo (texture and colour) and outline.gdshader as the next pass. Rigs and clips keep animating (only materials change).

  • func apply(node: Node) -> void
