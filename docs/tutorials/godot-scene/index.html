A small scene in Godot

You export everything from the earlier tutorials in one go, add the Gen Studio dock to the Godot editor, and build a small scene: the courier walking on a cobbled street beside a lantern, a pond, a blue flame, with the theme playing. About 15 minutes.

You'll make:

  • one Godot scene that uses a prop, a character, a texture, a shader, an effect, sounds and music

You'll learn:

  • exporting a whole project at once, and what lands where
  • the dock: the queue and Import inside the editor
  • that a retake reaches your scene by exporting again

Before you start​

  • The assets from your first prop, a character that moves, textures, shaders and effects and sound and music. You can follow along with fewer.
  • A Godot 4 project: a folder with project.godot.
  • No stale steps. Export refuses a stale asset, so Godot never gets a half-updated model.

Export everything​

  1. In Gen Studio, press Assets in the top bar (Ctrl+2). On the left, click Stale. If anything is listed, open it and press Re-run stale.
  2. Click Not exported to see what Godot doesn't have yet.
  3. Go to Home (Ctrl+1) and press Export to Godot. It exports every finished asset that isn't stale.
Checkpoint

in Godot's FileSystem panel, res://assets/gen/ has one folder per asset.

In res://assets/gen/What's inside
lantern/the Game mesh .glb
courier/the rig .glb, with every clip inside
cobblestone/the maps and material.tres
pond_water/the .gdshader
blue_flame/the sprite sheet and its materials
bottle_clink/, door_creak/, village_theme/.ogg files; the track has its loop points set
market_dialogue/Dialogue Manager files

From a terminal it's one asset at a time:

gen export lantern ~/games/lantern-village
gen export courier ~/games/lantern-village

Add the dock​

The dock is a small editor plug-in. It shows the queue and imports finished assets. It makes nothing itself.

  1. Install it into the Godot project:

    gen dock install ~/games/lantern-village

  2. Start the server for your Gen Studio project, and leave it running:

    gen serve --project ~/gen/lantern-village

  3. Reopen the game in Godot. The Gen Studio dock appears and says Connected.

  4. Find lantern under Assets and press Import beside it. It does what Export to Godot does, from this side.

Checkpoint

the dock lists your assets with their kinds, and none is marked stale.

The dock keeps the server's address and a token in addons/gen_studio/server.json. Don't commit that file to a public repository: the token lets anyone on your network use the queue.

Build the scene​

These steps are in the Godot editor.

  1. Make a new 3D scene and save it as village.tscn.

  2. Add a MeshInstance3D with a PlaneMesh for the street. Drag cobblestone/material.tres onto it.

  3. Add a second, smaller plane for the pond. Give it a new ShaderMaterial and set its shader to the .gdshader in pond_water/. The shader's uniforms show as sliders in the inspector.

  4. Drag the lantern's .glb and the courier's .glb into the scene, and stand them on the street.

  5. Select the courier's AnimationPlayer and play the walk. Clips whose names end in _loop loop.

  6. Add a GPUParticles3D for the flame and give it the particle material from blue_flame/.

Checkpoint

you see the street, the pond rippling, the lantern, the courier walking on the spot, and the flame.

Now the sound:

  1. Add an AudioStreamPlayer, set its stream to the .ogg in village_theme/, and turn on Autoplay. The loop points are already in the file.
  2. Add an AudioStreamPlayer3D near the lantern. Give it an AudioStreamRandomizer and add the variants from bottle_clink/ to it. Each play picks one, so it doesn't sound the same twice.
  3. Run the scene.
Checkpoint

the theme plays and loops, and the scene looks like the picture at the top.

Change something​

  1. Back in Gen Studio, open lantern, go to Game mesh and press Retake with a different Triangle budget.
  2. Use the new take, then press Export to Godot, or Import in the dock.
Checkpoint

the lantern in village.tscn changed without you touching the scene. Export replaces the files in place, so scenes that use them pick up the change.

What you learned​

  • Export to Godot on Home does the whole project, and res://assets/gen/<asset>/ is where each asset lands.
  • The dock is the same export, from inside the editor.
  • Your scenes point at files that Gen Studio replaces, so a retake is an export away.

If it went wrong​

  • Export refuses: stale steps, or the wrong folder. See troubleshooting.
  • The model looks wrong in Godot: see troubleshooting.
  • The dock says "not reachable", or doesn't show: the Godot dock has its own troubleshooting.
  • What each exported file is: export to Godot and Godot scripts.
