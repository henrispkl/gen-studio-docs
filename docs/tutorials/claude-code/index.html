Working with Claude Code over MCP

You connect Claude Code to a project and have it run Gen Studio for you: make assets, look at the takes, pick, retake and export. About 10 minutes.

You'll make:

  • a prop, made, picked and exported by an agent

You'll learn:

  • how to install the MCP server and its skill
  • which tools the agent uses, and what it sees
  • what it leaves to you

Before you start​

  • Claude Code installed.
  • A project with a working setup: do your first prop first.
  • Work faster introduces this in a few steps. This page has the detail.

Connect it​

  1. Run this once:

    gen mcp install --project ~/gen/lantern-village

    It adds the gen-studio MCP server at user scope, and the gen-studio skill.

  2. Start a new Claude Code session.

  3. Ask what it can see: what's in my Gen Studio project?

Checkpoint

the agent lists your assets and their steps.

Give it a job​

  1. Ask for something with a choice in it:

    Make a wooden barrel. Show me two takes of the concept, use the better one and export it to ~/games/lantern-village.

  2. Watch it work. It starts the job, waits, and looks at the takes as pictures.

  3. Open the app beside it. The same asset is there with the same takes: the agent and the app share the project and the queue.

  4. Ask it to change something: the hoops should be iron, not rope. It retakes the step, or adds a Retouch or an Edit part step.

Checkpoint

the barrel is in the project and in Godot, and the agent said which take it used and what it saw.

What it uses:

  • make, wait, job: start and follow jobs;
  • look, compare: see takes as pictures (four views of a model, frames of a clip, a sound's waveform);
  • asset, next_steps, add_step, fields, retake, use, run_to: the step graph;
  • make_mask, select_part: the area to retouch or the part to edit, when naming it isn't enough;
  • check, export: Godot's import checks, then the export.

What it leaves to you​

  1. Ask it for something that needs a model you don't have. It asks you before a download.
  2. Ask it to delete a step. It can only move steps and takes to the project's .trash.
  3. Ask it to turn on an extension. It tells you the command: extensions and library folders are yours.
Checkpoint

in each case the agent stopped and asked, or handed you a command, and didn't act on its own.

Several games​

gen mcp install --scope project --project ~/your-game gives each game its own server in a .mcp.json in the game's folder. Without it, one server works on one project, and the install says when it kept an existing one.

What you learned​

  • One command connects Claude Code to a project.
  • The agent sees takes as pictures and uses the same steps you do.
  • Downloads, deleting and extensions stay in your hands.

Next​

Every tool is in the MCP reference. To have the agent judge shader looks: a shader from a description.

If it went wrong​

  • The agent has no Gen Studio tools: run gen mcp install again and read what it prints, then start a new session.
  • It works on the wrong project: see Several games above.
  • A step it started failed: it's the same queue. See use the queue and troubleshooting.
